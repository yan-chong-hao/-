# 严崇豪摄影摄像作品集

React + Vite 的 PC 优先作品集基础版本。

## 运行

请先在已安装 Node.js 20+ 的环境中执行：

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 后续替换内容

- `src/main.jsx` 的 `projects` 数组：替换为真实作品图片、标题与项目说明。
- Hero 的 `<source>`：替换为自己的 MP4 视频地址或项目内视频文件。
- About 的人物图片和 Contact 区域提示文字：替换为本人照片、真实电话、邮箱与社交账号。

当前所有远程图片均为 Unsplash 占位图，卡片已明确标记为「视觉方向占位」。页面文字仅采用简历已确认的经历、能力与数值。
